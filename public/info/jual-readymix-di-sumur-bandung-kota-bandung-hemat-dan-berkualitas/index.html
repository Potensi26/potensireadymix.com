Kebutuhan Readymix = Volume Beton x Perbandingan Campuran x Densitas Campuran

Kebutuhan Readymix = 7.5 m³ x 1 : 2 : 3 x 2.4 ton/m³

Kebutuhan Readymix = 18 ton
