Cara Menghitung Kebutuhan Readymix

Untuk menghitung kebutuhan readymix, Anda perlu mengikuti langkah-langkah berikut:

2. Menghitung volume: Hitung volume struktur dengan rumus panjang x lebar x tinggi. Hasilnya adalah volume struktur dalam satuan meter kubik (m³).

3. Menghitung kebutuhan readymix: Setelah mendapatkan volume struktur, kalikan volume tersebut dengan angka konversi. Angka konversi ini bergantung pada jenis struktur yang akan dibangun. Misalnya, untuk beton pondasi biasa, angka konversi adalah 0,4. Jadi, kebutuhan readymix = volume struktur x 0,4.

4. Contoh perhitungan: Misalnya, Anda ingin membuat pondasi dengan dimensi 5m x 3m x 0,5m. Volume pondasi = 5m x 3m x 0,5m = 7,5 m³. Kebutuhan readymix untuk pondasi ini = 7,5 m³ x 0,4 = 3 m³.
